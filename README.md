# 🎓 Campus Connect

### Digital Campus Event Registration & Management Platform

**Campus Connect** is a web-based digital campus event registration and management platform designed to simplify the way students discover, register for, and manage campus events.

The platform provides a centralized system for managing college events, student registrations, event information, and participation.

> 🚧 **Project Status:** Currently under development
> 💻 **Technology:** MERN Stack

---

## 📌 Overview

Managing campus events through traditional methods can be time-consuming and difficult to organize. **Campus Connect** aims to provide a digital solution where students and event organizers can interact through a single platform.

The system is being developed to support:

* 📅 Campus event discovery
* 📝 Online event registration
* 👨‍🎓 Student participation management
* 🎯 Event management
* 📊 Registration tracking
* 🔐 User authentication and authorization
* 📱 Responsive and user-friendly interface

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/campus-connect.git
```

### 2. Navigate to the Project

```bash
cd campus-connect
```

### 3. Install Frontend Dependencies

```bash
cd Frontend
npm install
```

### 4. Install Backend Dependencies

```bash
cd ../Backend
npm install
```

### 6. Start the Backend

```bash
node app.js
```

### 7. Start the Frontend

Open another terminal:

```bash
cd Frontend
npm run dev
```

The application will then be available through the local development URL provided by Vite.
